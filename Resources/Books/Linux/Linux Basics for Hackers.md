# Linux Basics for Hackers

**Author:** OccupyTheWeb / **Edition:** 2025

A project based introduction to Linux: filesystem, permissions, package management, networking, bash scripting, taught through Kali Linux. The actual content is genuine Linux fundamentals, not an offensive-security guide like most beginners would assume.
