# Docker Deep Dive

**Author:** Nigel Poulton / **Edition:** 2025 

Covers images, containers, Docker Compose, networking, and registries for complete beginners.
It is actively and continuously revised and recommended in r/docker / r/selfhosted threads as the best beginner/intermediate Docker book. 
Matters a lot for homelabbing, since many self-hosted app stacks run in Docker Compose.
