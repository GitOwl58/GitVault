# Mastering Proxmox

**Author:** Wasim Ahmed  / **Edition:** 2018

The most reputable and professionally-published Proxmox book.
Teaches building and managing Proxmox VE environments: storage, clustering, networking, backups. 
Talks about what a hypervisor actually does, cluster architecture, but covers Proxmox VE 5 — the UI and several features have changed a lot since. 
Pair with the official Proxmox VE wiki.
