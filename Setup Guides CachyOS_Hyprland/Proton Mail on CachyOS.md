# Proton Mail on CachyOS / Hyprland with Proton Bridge

## What this will do:

Your Proton Mail inbox in Thunderbird. Proton Bridge runs in the background on your machine, decrypts your mail locally, and serves it to Thunderbird over a local IMAP/SMTP server. 
Bridge only works with a **paid** Proton plan. On a free account the login is refused.

## 1. Install Thunderbird and Bridge

```bash
sudo pacman -S thunderbird protonmail-bridge
```

## 2. Log in to Bridge

1. Open Proton Mail Bridge from your app launcher.
2. Log in with your real Proton credentials (username, password, 2FA code if enabled).
3. Wait for the first sync to finish. This can take a while on a big mailbox.
4. When asked for your mail client, select **Mozilla Thunderbird**.
Bridge now shows the settings Thunderbird needs: hostname, ports, security, username, and a **Bridge password**.

The Bridge password is not your Proton password. It's a separate password generated by Bridge, only valid for the local connection between Thunderbird and Bridge.

## 3. Add the account in Thunderbird

1. Open Thunderbird and start adding a mail account.
2. Enter a display name (what recipients will see see) and your Proton email address.
3. **Don't let Thunderbird auto configure.** Choose **Configure manually**. 
4. Copy every setting from the Bridge window into the manual config:

|Setting|Incoming (IMAP)|Outgoing (SMTP)|
|---|---|---|
|Hostname|`127.0.0.1`|`127.0.0.1`|
|Port|as shown in Bridge (default `1143`)|as shown in Bridge (default `1025`)|
|Connection security|as shown in Bridge (usually STARTTLS)|as shown in Bridge (usually STARTTLS)|
|Authentication|Normal password|Normal password|
|Username|your full Proton address|your full Proton address|

5. Set authentication to **Normal password**, not the default Auto detect.
6. Click **Done** and paste the **Bridge password** when Thunderbird asks for it.
7. Thunderbird will warn about Bridge's certificate, because it's self-signed by Bridge on your machine. Confirm the security exception and store it. That's expected for a connection to `127.0.0.1`.

Your folders should start appearing. Done.

## 4. Start Bridge automatically at login

Thunderbird only gets mail while Bridge is running. In Bridge's settings, enable **Automatically start Bridge**.

Reboot and check that Bridge is in your tray or running (`pgrep -a bridge`). If it didn't start on Hyprland, add it to your Hyprland config instead:

```ini
exec-once = protonmail-bridge --no-window
```

## 5. How it behaves

Everything goes through Bridge locally. Mail is decrypted on your machine and served to Thunderbird over `127.0.0.1`, so nothing unencrypted leaves your PC.

- **Bridge closed = no mail.** Thunderbird will show connection errors until Bridge is running again.
- **Sending works the same way.** Thunderbird hands mail to Bridge over SMTP, and Bridge encrypts and sends it through Proton.
- **The Bridge password is per device.** If you reinstall or set up another machine, you get a new one.
- **Changes sync both ways.** Read, move, or delete something in Thunderbird and it happens in Proton webmail too.
