# How Linux Works

**Author:** Brian Ward / **Edition:** 2021

What's actually happening when you launch Linux: boot process, kernel, filesystems, devices, networking, system configuration. Basic CLI usage before reading this book, so it's the natural next step after books like [[The Linux Command Line]]. 
Most recent edition is 2021, but it's still consistently quoted as the top "how Linux really works" recommendation.
