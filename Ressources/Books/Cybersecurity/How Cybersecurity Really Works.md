# How Cybersecurity Really Works

**Author:** Sam Grubb / **Edition:** 2021

Written for beginners, zero technical background. 
Explains how attackers operate (phishing, malware, network attacks), how defenses counter them, with  exercises (including setting up a small home lab). 
Good for learning by actually doing.
