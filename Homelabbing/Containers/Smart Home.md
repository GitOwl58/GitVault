# Smart Home

Bringing smart home devices under one roof (literally and figuratively) instead of scattering them across a dozen vendor apps and clouds.

### Options
- **[[Home Assistant]]**: the hub for essentially everything, integrates with thousands of device brands and protocols, and is where automations actually get built.
- **[[Mosquitto (MQTT)]]**: the lightweight messaging broker a lot of smart home devices (and Home Assistant integrations) use to talk to each other.
- **Octoprint**: 3D printer monitoring and control over the network, worth a mention if the "homelab" extends into a workshop.
- **MagicMirror**: a dashboard framework for building a smart mirror or wall-mounted info display, more of a fun project than core infrastructure.
