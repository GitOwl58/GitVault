# Audiobookshelf

A dedicated self-hosted server for audiobooks and podcasts, with a purpose-built mobile app (playback position sync, sleep timer, variable speed) rather than repurposing a general media server for something it wasn't really designed for. Organizes by author/series, pulls metadata automatically, and supports multiple libraries (audiobooks and podcasts can live side by side).

A common pairing: **[[Readarr]]** or manual downloads to acquire files, Audiobookshelf to actually serve and play them.
