# AppArmor

A Mandatory Access Control (MAC) system implemented as a Linux Security Module, using per-application profiles to define what resources each app can access, rather than a single kernel-wide policy like **[[SELinux]]**. Easier to use and configure than SELinux, at the cost of somewhat less fine-grained control.
