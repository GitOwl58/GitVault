# Nmap

  

Open-source network scanner, first published in 1997. Discovers which hosts on a network are alive and which network services they're running, without the impracticality of manual tools like `ping`, `arp-scan`, or one-by-one `telnet` probes. Targets can be specified as an IP range (`192.168.0.1-10`), a subnet (`192.168.0.1/24`), or a hostname. Almost always run as root, since a non-root user is limited to basic scan types.
