# Ports

Numbered endpoints (0-65535) where data is exchanged on a device — let multiple applications share one IP address without conflict. Source port is usually random; destination port is fixed by convention (e.g. 80 for HTTP).

Common ports: FTP (21) · SSH (22) · HTTP (80) · HTTPS (443) · SMB (445) · RDP (3389)
