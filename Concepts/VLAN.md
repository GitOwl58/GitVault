# Vlan Virtual Local Area Network

Virtually splits devices within a network so they're treated separately even while sharing infrastructure (e.g. an Internet connection). Provides security by controlling which devices can communicate with each other — e.g. Sales and Accounting both reach the Internet but can't talk to one another.

Configured on a Layer 3 Switch.
