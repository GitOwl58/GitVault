# Binary (Base-2)

Computers understand two states, encoded as `0` and `1` — each digit is a **[[Bit]]**. Groups of 4 bits map to one [[Hexadecimal]] digit; groups of 8 bits form a **[[Byte]]**.

Example: `1001` = 1×2³ + 0×2² + 0×2¹ + 1×2⁰ = **9**

Used at [[OSI Model]] Layer 1 (Physical) to represent electrical signal states.
