# Hypervisor

Software that creates and manages [[VM]]s — divides a physical computer into multiple virtual ones, allocates CPU/memory/storage, keeps them isolated, and manages their lifecycle.

- **Type 1**: runs directly on hardware — fast, efficient, servers/data centers.
- **Type 2**: runs within an existing OS — easier to install, ideal for learning/testing (e.g. VirtualBox, VMware Workstation).
