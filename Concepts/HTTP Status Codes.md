# HTTP Status Codes

Code returned on the first line of an [[HTTP]] response, indicating the outcome of the request. Grouped into 5 ranges:

- **100–199 Informational**: first part of the request accepted, client should continue — rarely seen today
- **200–299 Success**: request completed successfully
- **300–399 Redirection**: client is pointed to a different resource
- **400–499 Client Error**: something was wrong with the request
- **500–599 Server Error**: the server failed to handle an otherwise valid request

Common codes: 200 OK · 201 Created · 301 Moved Permanently · 302 Found · 400 Bad Request · 401 Not Authorised · 403 Forbidden · 404 Not Found · 405 Method Not Allowed · 500 Internal Server Error · 503 Service Unavailable
