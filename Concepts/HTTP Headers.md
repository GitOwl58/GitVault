#type/concept #domain/networking

Additional key-value metadata sent between client and server in an HTTP request or response, giving context or instructions beyond the resource itself (e.g. what content-type is being sent, how to cache it, who the client is). No headers are required to make a request, but they're needed for a website to work properly.
Request headers and response headers serve different directions of the exchange.
