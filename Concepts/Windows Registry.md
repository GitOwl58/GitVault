# Windows Registry

A central hierarchical database that stores the configuration Windows needs for its users, applications, and hardware — profiles, installed apps and their file-type associations, folder/icon settings, installed hardware, and ports in use. Continually referenced during normal operation. Viewed/edited with the Registry Editor (`regedit`). Risky to edit carelessly — bad changes can break normal system operation.
