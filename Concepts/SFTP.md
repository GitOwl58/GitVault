# SFTP (SSH File Transfer Protocol)

Secure file transfer built into the [[SSH]] protocol suite, sharing SSH's port 22, enabled as an option on an OpenSSH server. Commands are Unix-like: `get filename` / `put filename` to download/upload. Not to be confused with [[FTPS]], which secures [[FTP]] with TLS instead.
