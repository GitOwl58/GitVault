# Trojan

A type of [[Malware]] disguised as legitimate, harmless software to trick a user into installing it. Unlike a [[Virus]], a Trojan does not self-replicate — it relies entirely on social engineering to get the user to run it, after which it can open a backdoor, install a [[Rootkit]], or deliver a [[Ransomware]] payload.
