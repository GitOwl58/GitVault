# ASCII

American Standard Code for Information Interchange — an early 7-bit character encoding from 1963, using numbers 0-127 to represent English letters, digits, punctuation, and control characters. Didn't support other European languages (accents, diacritics), leading to ISO-8859-1/2 and eventually [[Unicode]].
