# Linux Kernel

The core of the Linux operating system: virtualizes and controls hardware resources (CPU, memory, storage, I/O) and gives each process its own isolated virtual resources, preventing/mitigating conflicts between them. Started by Linus Torvalds in 1991 as a personal project; now over 23 million lines of C, licensed under the GNU GPLv2. Distinct from a **distribution**, which packages the kernel with supporting software and tools.
