# Virus

A type of [[Malware]] that attaches itself to a legitimate file or program and requires user action (opening/running the host file) to activate and spread. Once run, it can replicate itself into other files on the system, distinguishing it from a [[Trojan]] (which doesn't self-replicate) and a worm (which spreads on its own across a network without a host file).
