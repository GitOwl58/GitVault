# ADS Alternate Data Streams

A feature of NTFS allowing files to contain multiple hidden data streams alongside the main `$DATA` stream. Invisible to Windows Explorer by default — viewable via PowerShell or third-party tools. Legitimately used by Windows to mark downloaded files, but exploited by malware to hide malicious payloads inside innocent-looking files
