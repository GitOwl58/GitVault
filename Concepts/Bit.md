# Bit / Byte

- **Bit**: short for binary digit — either `0` or `1`. One bit represents 2 states (on/off).
- **[[Byte]]**: a group of 8 bits (also called an **octet**) — represents 256 states, enough for one color channel (256 × 256 × 256 = 16,777,216 possible RGB colors).
