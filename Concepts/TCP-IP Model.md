# TCP/IP Model

The implemented (vs [[OSI Model]]'s theoretical) networking model — developed in the 1970s by the US DoD so the network keeps functioning even if parts go down. Groups OSI's layers 5-7 (Session/Presentation/Application) into one **Application** layer; layer 3 is renamed the **Internet** layer.

| TCP/IP layer | = OSI layer(s) |
| ---- | ---- |
| Application | 7, 6, 5 |
| Transport | 4 |
| Internet | 3 |
| Link | 2 (some textbooks add Physical, layer 1, as a 5th) |
