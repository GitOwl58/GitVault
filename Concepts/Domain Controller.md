# Domain Controller

The server that runs [[Active directory]] services for a [[Windows domain]]. It hosts the centralised repository of users, machines, and groups, and handles authentication requests (e.g. issuing [[Kerberos]] tickets) so credentials don't need to exist on every machine in the network.
