# File System Hierarchy

The FHS (Filesystem Hierarchy Standard) defines Linux's standard top-level directory layout, rooted at `/`: `/bin` (essential binaries), `/boot` (bootloader/kernel), `/dev` (device files), `/etc` (config), `/home` (user data), `/lib` (shared libraries), `/media`/`/mnt` (removable/temporary mounts), `/opt` (third-party software), `/root` (root's home), `/sbin` (admin binaries), `/tmp` (scratch space, cleared on boot), `/usr` (executables, libraries, docs), `/var` (logs, mail, variable data). Solaris follows a broadly similar but distinct layout (adds `/kernel`, `/lost+found`).
