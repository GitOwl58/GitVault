# systemd

The init system used by Ubuntu and most modern Linux distributions — the first process started at boot ([[PID]] 1), from which every other process descends as a child. Manages starting, stopping, and enabling services via `systemctl` (e.g. `systemctl start apache2`), sitting between the kernel and user-space processes.
