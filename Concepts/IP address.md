# IP address

Identifies a host on a network for a period of time. A set of numbers divided into four octets (e.g. 192.168.1.100). Calculated through IP addressing and subnetting.

- **Private** IP: identifies a device among other devices on the same network.
- **Public** IP: identifies the device on the Internet as a whole, assigned by an ISP.

Works alongside MAC address via ARP. Used at OSI model Layer 3 for Routing. Growing device count is pushing adoption of **IPv6** over IPv4.
