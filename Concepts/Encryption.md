# Encryption

The process of converting readable data (plaintext) into an unreadable form (ciphertext) using an algorithm and a key, so that only someone holding the correct key can reverse it. Underpins [[Cryptography]] as a whole and is used both for data in transit (e.g. [[HTTP|HTTPS]]) and data at rest (e.g. [[EFS]] on Windows).
