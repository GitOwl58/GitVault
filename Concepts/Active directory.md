# Active Directory

Microsoft's directory service for a [[Windows domain]], a single, centralised repository for administering users, machines, and groups across the network. It's why credentials don't need to exist on every machine (a login is forwarded to AD for checking) and why security policies can be configured once and applied network-wide. Its core, **AD DS**, catalogues objects such as users, machines, and [[Security Groups]], organised into **Organizational Units (OUs)**. Runs on the [[Domain Controller]], and issues [[Kerberos]] tickets for authentication.
