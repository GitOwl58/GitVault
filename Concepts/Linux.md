# Linux

Linux is a command line operating system based on unix. There are multiple operating systems that are based on Linux.
Not a single OS but a family of open-source distributions (Ubuntu, Debian, Fedora, CentOS, Red Hat). Powers the vast majority of web servers, trusted for reliability and its open-source nature. Common as a [[VM]] or [[Container]] base image.
