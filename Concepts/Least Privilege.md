# Least Privilege


A security principle stating that users, programs, and systems should only have the minimum permissions necessary to perform their function — nothing more. Limits the damage an attacker can do if they compromise an account or process. Using a Standard User account for daily tasks instead of Administrator is a direct application of this principle.
