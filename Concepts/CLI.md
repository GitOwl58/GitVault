# CLI (Command-Line Interface)

A text-based interface where you type commands to control the system with precision and speed. More powerful than a [[GUI]] for advanced tasks, but requires knowing the correct syntax.

Commands differ by OS: see [[7. Linux CLI Basics]] and [[8. Windows CLI Basics]].
