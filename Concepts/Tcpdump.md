# Tcpdump

Command-line packet sniffer and analyser, pre-installed on most Linux systems. Captures live traffic off a network interface or reads back a saved `.pcap` file, then filters and displays the result entirely through command-line flags, no GUI. Where [[Wireshark]] is built for visual, exploratory inspection, tcpdump is built for quick, scriptable capture, often the first tool reached for on a remote box that doesn't have a GUI available.
