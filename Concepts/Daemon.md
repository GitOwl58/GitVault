# Daemon

A background service in Linux, typically named with a trailing "d" (`sshd`, `systemd`). Daemons handle key ongoing functions (scheduling, printing, multimedia, networking) and are started after boot or login rather than run interactively. Windows' rough equivalent is a background service.
