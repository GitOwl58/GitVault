# WHOIS

Public lookup of a registered domain's registrant info (name, phone, email, address, creation/update dates) — not an acronym, pronounced "who is." Registering a domain requires providing this info; privacy services can hide it from public WHOIS records. Queried via the `whois` CLI tool or an online service.
