# TPM (Trusted Platform Module)

A dedicated hardware crypto-processor built to perform cryptographic operations and resist physical tampering, so malicious software can't interfere with its security functions. Used by Windows features like BitLocker — a TPM (v1.2+) both strengthens drive encryption and helps verify the system hasn't been tampered with while offline.
