# ARP Spoofing

Attack where an attacker sends forged [[ARP]] replies to associate their own MAC address with another device's IP (often the gateway), poisoning victims' ARP caches so their traffic routes through the attacker — a common way to get on-path for a [[MITM]] attack (e.g. to set up [[DNS spoofing]]).
