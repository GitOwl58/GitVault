# HTTP Methods

The action a client intends to perform when making an [[HTTP]] request.

- **GET**: retrieve info from a web server
- **POST**: submit data to a web server, potentially creating new records
- **PUT**: submit data to update existing info
- **DELETE**: delete info/records from a web server
