# Regular Expressions

A pattern language (regex) for searching, matching, and manipulating text, built from literal characters plus metacharacters, symbols with no literal meaning that define the pattern itself. Used across programming languages and tools (e.g. [[grep]], [[sed]]) and commonly for input validation. Key grouping operators: `(a)` groups a sub-pattern, `[a-z]` defines a character class, `{1,10}` sets a repeat-count quantifier, `|` is OR (matches either side), `.*` acts as an AND-like wildcard span. Extended regex (`grep -E`) enables the `|`/`.*` forms.
