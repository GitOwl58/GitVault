# Windows domain

A set of users and computers managed together in a business organization, administered centrally through [[Active Directory]] rather than machine by machine. Most people have already interacted with one without realising it — e.g. a school or work network where the same username/password logs into any machine on campus, because each machine forwards the authentication request back to the domain's [[Domain Controller]] instead of checking a local account.
