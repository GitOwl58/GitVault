# Switch

A networking device that aggregates multiple devices (computers, printers, etc.) via ports (4/8/16/24/32/64). Keeps track of which device is connected to which port, so it sends packets directly to the intended target rather than repeating to all devices (unlike a hub) — reducing network traffic.

Operates at Layer 2 or Layer 3 of the OSI Model (mutually exclusive — a Layer 2 switch cannot do Layer 3 work).
- **Layer 2**: forwards Frames to devices using MAC address only.
- **Layer 3**: also routes packets using IP address, and can host VLANs.
