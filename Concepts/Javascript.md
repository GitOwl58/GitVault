# Javascript

Originally built to run client-side in web browsers. Since Node.js, it also runs server-side, making it usable across the full stack.

Key syntax: `let` (variable, changeable) vs `const` (constant, fixed) · `console.log()` (print to screen) · `Math.random()` / `Math.floor()` (generate/round random numbers)
