#domain/networking
### Web server
A web server is a software that listens for incoming connections and then utilises the protocol to deliver web content to its clients.
**Popular web servers**

- Apache HTTP Server
- Nginx
- Microsoft IIS
- LiteSpeed
- Caddy
- Tomcat (Java)
- Node.js (Express)
- Gunicorn / uWSGI
- Lighttpd
- OpenLiteSpeed
