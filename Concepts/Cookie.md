# Cookie

Small piece of data stored on the client's computer, set when a `Set-Cookie` response header is received from a web server. Sent back to the server on every subsequent request.

Since [[HTTP]] is stateless, cookies are what let a site remember who you are, personal settings, or whether you've visited before.
