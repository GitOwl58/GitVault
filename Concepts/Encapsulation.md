# Encapsulation

The process of adding information (headers) to data as it moves down through the OSI Model layers — e.g. a Packet gets wrapped into a Frame by adding a MAC address. Like an envelope wrapping a letter.

Reverse process: **[[Decapsulation]]** — headers get stripped away as data moves up the layers on the receiving end.
