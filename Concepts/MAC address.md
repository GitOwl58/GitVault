# MAC address

A unique twelve-character Hexadecimal number assigned to a device's physical network interface at the factory (like a serial number). Added at OSI Model Layer 2 (Data Link).

Can be **spoofed** (faked) to impersonate another device — can break poorly implemented security that trusts known MAC addresses (e.g. firewall rules, guest Wi-Fi controls).

Linked to an IP address via ARP.
