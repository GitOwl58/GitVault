# POP3 (Post Office Protocol v3)

Downloads email from a server to one client, typically deleting it server-side afterward — minimizes server storage but doesn't synchronize across devices. TCP port 110 by default. Key commands: `USER`/`PASS`, `STAT`/`LIST`, `RETR <n>`, `DELE <n>`, `QUIT`.
