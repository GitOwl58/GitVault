# Container

A lightweight, isolated environment that runs a single application plus its dependencies. Shares the host's kernel (unlike a VM, which brings a whole OS), so it starts almost instantly, uses fewer resources, but must match the host system's OS type.

Deployed most commonly via **[[Docker]]**, or via **[[LXC]]** for lighter-weight, more manual Linux-native containers.
