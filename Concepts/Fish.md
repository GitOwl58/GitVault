# Fish

Friendly Interactive Shell — not installed by default on most distros, built for user-friendliness over [[bash]]: simple syntax, automatic spell correction of commands, syntax highlighting built in (colors commands by role, helps spot errors). Also has scripting, tab completion, and command history like other shells.
