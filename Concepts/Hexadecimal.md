# Hexadecimal (Base-16)

Every 4 Binary digits (bits) group into one hex digit, ranging `0`–`F`. Makes long binary strings easier to read and write.

Used to represent [[MAC address]]es (12 hex characters) and colours (e.g. hex color codes).
