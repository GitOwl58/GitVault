# Vim

A powerful, modal text editor (an improved *Vi*) that delegates specialized tasks to external tools (`grep`, `awk`, `sed`) rather than reimplementing them: small, fast, and flexible, in the Unix small-composable-programs spirit. Six modes: **Normal** (default, input = commands), **Insert** (typed text is inserted), **Visual** (select/highlight text), **Command** (single-line commands, entered via `:`), **Replace** (typed text overwrites). `:q` quits; `vimtutor` (or `:Tutor` from inside Vim) is a ~25-30 minute built-in tutorial.
