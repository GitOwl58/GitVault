# Security Groups

An [[Active directory]] object used to grant permissions over resources — users and machines can be added as members and automatically inherit all of the group's privileges. The **Domain Admins** group, for example, normally administers all computers and resources in a domain.

Unlike an [[Organizational Unit]] (used to apply policies to a set of accounts), Security Groups exist to grant permissions.
