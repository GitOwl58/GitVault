### How do you declare variables and what naming conventions to name variables?

[[Variables (Python)]] are like labeled boxes storing and referencing data of different types.
To declare variables you assign a value to an identifier with the assignment (=) operator.
You just write the name of the variable on the left, followed by the assignment operator, and the value you assign it on the right,
Example with name and age:
`name = 'John Doe'
`age = 25
The variable `name` holds the value of `'John doe'`.
This value is a string, a series of characters used to represent text. Strings are written with single or double quotes, `'Hello'` `"Hello"`.
- Variables names can only start with a letter or _ , no numbers.
- Variable names can only contain alphanumeric `a-z A-Z 0-9` and `_`.
- Variable names are case sensitives, `age` `Age` `AFE` are considered unique.
- Variable names cannot be one of Python's Keywords such as `if` `class` `def`.
Any of these rules gets broken and it's a `SyntaxError`.

Common naming conventions for variables in Python:
- Variables should be lowercase, words separated by an underscore.
`my_variable_name = 'freeCodeCamp'`
- Descriptive names should be used for variables, if you want to save a user's age,
`user_age = 30` is better than `age` or `ua`.
- avoid using single letter variable names, they communicate no purpose, nor meaning,
`x = 56 # What do you mean by x ?`
- The # and the text following is called a comment. Multi line comments can be created with consecutive single line comments, you can use comments to explain a variable, however it is better to use descriptive variable names.
` # This is a
` # multi-lin
` # comment`


### How does the print [[function (Python)]] work?

Every programming language has some way to output data to the terminal, in Python, you can use `print` to print data to the terminal.
`Print('Hello World!) # Hello world!`
[[Strings (Python)]] are sequences of characters surrounded by single or double quotes.
In the [[print (Python)]] `print('Hello World')`, the string Hello World is an [[argument (Python)]], passed to the `print` function.
The `print` function can also be used to show multiple values or arguments at once by separating them with commas:
`print('My favorite colors are', 'blue', 'green', 'red')
`# Output: My favorite colors are blue green red`
Python adds a space between each item when separated with commas.

###  What are common data types in Python?

A data type describes the kind of value held by the variable, a number, a piece of text, a list of items.
Unlike C#, Java or C++, Python and JavaScript are dynamically typed languages, no need to declare types for variables, the language know what data type a variable is base on what you assign to it.
```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```
Dynamic typed languages make coding faster but can lead to bug, as the language does not get compiled before running the program, it runs line by line, and will stop and show an error if a mistake has been done somewhere.
- [[Integer (Python)]]: A whole number without decimals, for example 10 or -5
```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```
- [[Float (Python)]]: A number with decimal point like 4.41 or -0.4
```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```
- [[Strings (Python)]]: A sequence of characters enclosed in single or double quotations
```python
my_string_var = 'hello'
print('String', my_string_var) # hello
```
- [[Boolean (Python)]]: A true or false type, written as true or false
```python
my_boolean_var = True
print('Boolean', my_boolean_var) # True
```
- [[Set (Python)]]: An unordered collection of unique elements, like `{0.5, 4, 'apple'}`
```python
my_set_var = {7, 'hello', 8.5}
print('Set:', my_set_var) # Set: {8.5, 'hello', 7} (order may vary)
```
[[Concepts/Dictionary (Python)]]: A collection of key value pairs enclosed in curly braces
```python
my_dictionary_var = {'name': 'Alice', 'age': 25}
print('Dictionary:', my_dictionary_var) # Dictionary: {'name': 'Alice', 'age': 25}
```
- [[Tuple (Python)]]: An immutable ordered collection enclosed in parentheses
```python
my_tuple_var = (7, 'Hello', 8.5)
print('Tuple:', my_tuple_var) # Tuple: (7, 'Hello', 8.5)
```
- [[List (Python)]]: An ordered collection of elements that supports different data types.
```python
my_list_var = [22, 'Hello world', 3.14, True]
print('List:', my_list_var) # List: [22, 'Hello world', 3.14, True]
```
- [[None (Python)]]: A special value that represents the absence of a value.
```python
my_none_var = None
print('None:', my_none_var) # None: None
```
### How do the `type()` and `isinstance()` functions work?

Python provides the `type()` and `isinstance()` functions to identify and check data types.

## The `type()` Function

Use `type()` to see the data type of a variable.

```python
developer = 'Devin'

print(type(developer))  # <class 'str'>
```

Output:

```python
<class 'str'>
```

This means `developer` is a string (`str`).

If `type()` is called without any arguments, Python raises an error:

```python
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: type() takes 1 or 3 arguments
```

### Examples of `type()`

```python
my_integer_var = 10
print(type(my_integer_var))  # <class 'int'>

my_float_var = 4.50
print(type(my_float_var))  # <class 'float'>

my_string_var = 'hello'
print(type(my_string_var))  # <class 'str'>

my_boolean_var = True
print(type(my_boolean_var))  # <class 'bool'>

my_set_var = {7, 'hello', 8.5}
print(type(my_set_var))  # <class 'set'>

my_dictionary_var = {'name': 'Alice', 'age': 25}
print(type(my_dictionary_var))  # <class 'dict'>

my_tuple_var = (7, 'hello', 8.5)
print(type(my_tuple_var))  # <class 'tuple'>

my_range_var = range(5)
print(type(my_range_var))  # <class 'range'>

my_list = [22, 'Hello world', 3.14, True]
print(type(my_list))  # <class 'list'>

my_none_var = None
print(type(my_none_var))  # <class 'NoneType'>
```

## The `isinstance()` Function

Use `isinstance()` to check whether a variable is a specific data type before performing operations on it.

```python
account_balance = '12'
```

Trying to perform mathematical operations on a string raises an error:

```python
account_balance = '12'

account_balance / 2

# Traceback (most recent call last):
#   File "<stdin>", line 1, in <module>
# TypeError: unsupported operand type(s) for /: 'str' and 'int'
```

Check whether `account_balance` is an integer:

```python
account_balance = '12'

isinstance(account_balance, int)  # False
```

`isinstance()` takes an object and the type to check against, then returns a boolean. Since `account_balance` is a string, it returns `False`.

### Checking Multiple Types

`isinstance()` can also check for multiple data types at once.

```python
account_balance = 12
isinstance(account_balance, (int, float))  # True
```

In this example, `account_balance` is an integer, so `isinstance()` returns `True`. If `account_balance` were `12.0`, it would still return `True` because the check includes both `int` and `float`.
