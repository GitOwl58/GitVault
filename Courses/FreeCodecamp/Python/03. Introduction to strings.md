### What are strings and what is strings immutability?

To create a multi line string you can use triple quotes:
```python
my_str_3 = '''Multi
line
string'''
```
If your string contains either single or double quotation marks you have two options:
- Use the opposite kind of quotes to wrap it up:
```python
msg = "It's a sunny day"
quote = 'She said, "Hello World!"'
```
or
- Escape the quotation mark with a backlash \.
```python
msg = 'It\'s a sunny day'
quote = "She said, \"Hello World!\""
```
To check if a string contains one or more characters, use `in` , returning a boolean:
```python
my_str = 'Hello World!'

print('Hello' in my_str) # True
print('Hey' in my_str) # False
print('Hi' in my_str) # False
print('e' in my_str) # True
print('f' in my_str) # False

```
### Length of a string

Use the built-in `len()` function to get the number of characters in a string, this process is called [[indexing (Python)]]
```python
my_str = 'Hello world'
print(len(my_str))  # 11
```

### Accessing characters by index

Each character in a string has a position called an **index**. Indexing is zero-based — the first character is at index `0`, the second at index `1`, and so on. Use square brackets `[]` with the index to access a character.
```python
my_str = "Hello world"

print(my_str[0])  # H
print(my_str[6])  # w
```

### Negative indexing

Negative indices count from the end of the string: `-1` is the last character, `-2` the second-to-last, and so on.
```python
my_str = 'Hello world'
print(my_str[-1])  # d
print(my_str[-2])  # l
```

### Mutable vs. immutable types

Many languages split data types into primitive (simple, immutable) and reference (can hold multiple values, mutable or immutable) types. Python doesn't draw that hard line — everything is an object, and some objects are mutable while others are immutable.

**Immutable** objects can't be modified once declared. You can _reassign_ their variable to point at something new, but you can't alter the original object by adding, removing, or replacing elements.

Strings are immutable. Reassignment works fine:
```python
greeting = 'hi'
greeting = 'hello'
print(greeting)  # hello
```

But direct modification is not allowed:
```python
greeting = 'hi'
greeting[0] = 'H'  # TypeError: 'str' object does not support item assignment
```

Other immutable types in Python: integer, float, boolean, tuple, and range.
### What are string concatenation and string interpolation?
With strings, combining different pieces of text together is common.
#### Concatenating strings
You can combine multiple [[Strings (Python)]] together with the `+` operator. This is called string concatenation.
```python
my_str_1 = 'Hello'
my_str_2 = 'World!'

str_plus_str = my_str_1 + ' ' + my_str_2
print(str_plus_str) # Hello World!
```
#### Repeating strings
You can also repeat a string, multiplying it with an integer using `*` operator.
```python
sound = 'ha'
repeated_sound = sound * 3
print(repeated_sound) # hahaha
```
### Concatenating strings with numbers
Concatenation only works with strings, if you try to concatenate a string with the number you will get a `TypeError`
This happens because Python does not automatically convert other data types like integers into strings when you concatenate them. ython requires all elements to be strings before it can concatenate them.
To fix that you convert the number into a string with the built in `str()` function.
```python
name = 'John Doe'
age = 26
name_and_age = name + str(age)
print(name_and_age) # John Doe26
```
### String interpolation
Inserting variables and expressions into a stirng is called string interpolation, this category is called f-strings
```python
name = 'John Doe'
age = 26
name_and_age = f'My name is {name} and I am {age} years old'
print(name_and_age) # My name is John Doe and I am 26 years old

num1 = 5
num2 = 10
print(f'The sum of {num1} and {num2} is {num1 + num2}') # The sum of 5 and 10 is 15
```
