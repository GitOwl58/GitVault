## 1. What is Python ?


[[Python]] is a general purpose programming language, simple, easy to use.
It is used in many fields like data science and machine learning, web development, scripting, automation, embedded systems, [[IoT]].
- Libraries like Pandas/NumPy for data analysis
- TensorFlow/Scikit-learn for machine learning/AI
- Python frameworks like Django/FastAPI/Flask in web development for developers (Instagram, Pinterest...)
- Used to detect vulnerabilities, build automated scans/analyze threats, for Cybersecurity.
- Runs well on microcomputers like RaspberryPi/MicroPython-compatible boards to build IoT projects.
- Widely used in DevOps to write CI/CD scripts, managing infrastructures.
- Python tools like Pytest to create reliable test suites, system administrators rely on Python for server monitoring, log management, system level tasks.
- Libraries like Selenium, BeautifulSoup make interact with websites easy, scrape public data...
Python's biggest strength is automation, writing simple scripts to help with repetitive tasks.
