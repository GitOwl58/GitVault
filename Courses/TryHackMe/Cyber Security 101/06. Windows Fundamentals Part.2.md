### System Configuration (MSConfig)
**MSConfig** is an advanced troubleshooting utility, mainly used to diagnose startup issues. Requires local administrator rights to open. Launchable from the Start Menu.

Five tabs:

- **General** — choose what loads on boot: Normal, Diagnostic, or Selective
- **Boot** — configure OS boot options
- **Services** — lists every configured service, running or not (a **service** is a special type of application that runs in the background)
- **Startup** — on Windows 10/11 this just tells you to use Task Manager instead, since Task Manager (`taskmgr`) is the real place to enable/disable startup items. MSConfig is **not** a startup manager.
- **Tools** — a list of built-in configuration utilities with a short description each. Selecting one shows the exact command to launch it, runnable from Run, Command Prompt, or the Launch button here.

⚠️ **Windows Server difference:** servers handle startup items differently from Windows 10/11 — no Startup tab in Task Manager or MSConfig. The only reliable way to check startup items on a server is the Startup folder itself: `Win + R` → `shell:startup`.

### Advanced System Settings
Reached via searching "View advanced system settings". Opens the **System Properties** panel, with two useful sub-sections under the **Advanced** tab:

**Performance → Settings** — shows/configures the **page file** (extra virtual memory used once physical RAM fills up, preventing slowdowns/crashes). Displays per-drive: location, initial size, maximum size, and whether Windows manages it automatically.

**Startup and Recovery → Settings** — configures what happens on a crash (e.g. Blue Screen of Death). The **Write debugging information** dropdown sets the crash dump type Windows saves for later analysis:

- Automatic memory dump
- Kernel memory dump
- Small memory dump (256 KB)
- Complete memory dump
- None

### UAC settings slider
[[UAC User Account Control]] (covered in Part 1) can be tuned via a 4-position slider found in the System Configuration tools:

- **Always notify** — highest security; notifies for any change (by apps or by you), dims the desktop (Secure Desktop)
- **Notify for apps** — default; only notifies when apps try to make changes, not for your own Windows setting changes
- **Notify without dimming** — same as above, no screen dimming
- **Never notify** — UAC effectively off, not recommended

### Computer Management (compmgmt)
Three sections: **System Tools**, **Storage**, **Services and Applications**.

**System Tools**

- **Task Scheduler** — create/manage tasks that run automatically (on a schedule, at logon/logoff, etc). **Task Scheduler Library** lists all scheduled tasks and their triggers (recurring or one-time).
- **Event Viewer** — an audit trail of everything that happened on the system, used to diagnose problems and investigate activity. Three panes: log providers (left), event summary (middle), actions (right). Standard logs live under **Windows Logs**.
- **Shared Folders** — lists shares (including Windows defaults like `C$` and admin shares like `ADMIN$`), active **Sessions** (who's connected), and **Open Files** (what connected users are accessing).
- **Local Users and Groups** — this is `lusrmgr.msc` from Part 1.
- **Performance** → **Performance Monitor (perfmon)** — real-time or logged performance data, useful for troubleshooting local or remote performance issues.
- **Device Manager** — view/configure attached hardware, including disabling devices.

**Storage**

- **Disk Management** — advanced storage tasks: set up a new drive, extend/shrink a partition, assign or change a drive letter. (Windows Server also exposes Windows Server Backup here, not covered.)

**Services and Applications**

- **Services** — lists every service with its status. Each service's **Startup type** is **Automatic** (starts on boot), **Manual** (starts only when triggered), or **Disabled**.
- **WMI** (Windows Management Instrumentation) — the underlying service that lets scripting languages (VBScript, PowerShell) manage local/remote Windows machines. The old CLI front-end **WMIC** is deprecated as of Windows 10 21H1 — PowerShell replaces it.

### System Information (msinfo32)
Gathers a full overview of hardware, components, and installed software for diagnosing issues. Three sections:

- **Hardware Resources** — low-level info, not needed by average users
- **Components** — installed hardware devices (some sections empty depending on system)
- **Software Environment** — software running/installed, plus **Environment Variables** and network connections

Has a built-in search bar at the bottom to jump straight to a value (e.g. search "IP address" under Components).

---
### Resource Monitor (resmon)
Shows per-process and aggregate CPU, memory, disk, and network usage, plus which processes hold which file handles — useful for finding deadlocks/file-locking conflicts without having to kill an app. Overview tab has four sections, each with its own dedicated tab: **CPU**, **Memory**, **Disk**, **Network**. A live graph pane sits on the far right.

### Command Prompt basics
A few useful commands for gathering system info:

- `hostname` — prints the computer name
- `whoami` — prints the logged-in user
- `ipconfig` — shows network address settings
- `netstat` — protocol statistics and current TCP/IP connections
- `net` — manages network resources via sub-commands (`net user`, `net localgroup`, `net share`, `net session`, etc.)
- `cls` — clears the screen

**Getting help:** most commands support `<command> /?` (e.g. `ipconfig /?`). The `net` command is the exception — its help syntax is `net help <subcommand>` (e.g. `net help user`).

### The Windows Registry
A central hierarchical database storing the configuration needed by the system, users, applications, and hardware. It's continually referenced by Windows during normal operation and holds things like:

- Per-user profiles
- Installed applications and their file-type associations
- Folder/icon property sheet settings
- Installed hardware
- Ports in use

⚠️ Advanced-user territory — bad edits can break normal operation. View/edit it with the **Registry Editor** (`regedit`).
