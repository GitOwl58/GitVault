### What is [[SSH]] and how does it work ?
SSH (Secure Shell) is a protocol between devices in an encrypted form. Using cryptography, any input we send in a readable format is encrypted for travelling over a network, then uncrypted once it reaches the remote machine.
- SSH allows us to remotely execute commands on another device.
- Any data between the devices is encrypted when sent over a network such as the internet.
The syntax is very simple :

`ssh nameofaccount@IPaddress
Then enter the password of the account.
From now you can execute commands remotely on the device.
### Introduction to flags and switches
A majority of commands allow arguments to be provided. Arguments are identified by a hypen (-) and a keyword (know as flag, or switch).
When using a command it will perform its default behaviour, flag/switches will extand the command's behaviour.
Example:
`ls` will list the contents of the working directory.
However, adding -a (short for --all) we can now also see hidden files and folders(.file).
`ls -a`
These commands acceptings flags will also have a `--help` option, listing the possible flag options, and providing a brief description.
### The [[man pages]]
Great source of information, both system commands and applications available on a Linux machine, accessible on the machine and online.
To access it, we can use the `man` command, and then the command we want to ready the documentation for.
Example :
`man ls`

### Creating files
- The `touch` command creates a blank file.
`touch example` Will create a blank file called example.
To add content to the blank files you'll need command such as `echo` or `nano`.
- The process to create a new fodler is similar with `mkdir`.
`mkdir Myexample` will create a new folder called Myexample.

### Removing files and folders
- You can simply remove files using `rm`.
`rm example`.
- For a directory you'll need to provide the `-R` flag alongside the directory.
`rm -R Myexample`.
### Copying and moving files and folders
- Copying takes two arguments, `cp` to copy, the name of the existing file, and the name you wish to assign to the new file.
`cp example example1` will create a copy of example, named example1.
- mv can be used to move or rename files and folders
Moving a file with `mv Source Destination`  `mv example Myexample.
Renaming a folder using `mv Filename Newname` `mv Example Example1.`
### Determining file type
- The command `file` can be used to determine what the purpose/content of a file is.
With `file Filename`. `file example` will determine if example is a text file, or else.
### Permissions 101
Certain users cannot access certain files or folders.
When using `ls`, you get a list of the files in the directory, adding the switch `-l`, we can see ten columns.
First three are for Owner, next 3 for Group, next 3 Others.
`r` for read
`w` for write
`x` for execute

`drwxr-xr-x`             
`d` Indicates it is a directory, not just a file
`rwx`Owner can read write execute
Followed by `r-x` Group can read, not write, can execute.
Ending with `r-x`, Others can read, not write, can execute.
#### Converting these symbolic permissions to number
| Permission    | Value |
| ------------- | ----- |
| Read (`r`)    | 4     |
| Write (`w`)   | 2     |
| Execute (`x`) | 1     |
Example in numeric value of `drwxr-xr-x`

| Group  | Permissions | Calculation | Value |
| ------ | ----------- | ----------- | ----- |
| Owner  | `rwx`       | 4 + 2 + 1   | 7     |
| Group  | `r-x`       | 4 + 1       | 5     |
| Others | `r-x`       | 4 + 1       | 5     |

So: `drwx r-x r-x = 755`.
### Common directories

#### /etc
This root directory is one of the most importants of your system.
It is a commonplace location to store system files used by your OS, you can find in there "passwd" and "shadow" files for example, special for Linux as they show how your system stores passwords for each user, encrypted in a format called sha512.
#### /var
This directory, short for variable data, is one of the main root folders on a Linux install. It stores data frequently accessed or written over by services and apps running on the system, log files from running services or app for example in /var/log, or other data not necessarily associated with a specific user (databases...)
#### /root
Unlike /home, the /root folder is the home for the root system user.
There isn't anything more to this than just understanding it is the home directory for root user.
#### /tmp
A unique root directory found on a Linux install. Short for temporary, this directory is volatile, used to store data needed only once or twice. Like the momery on your computer, once it's restarted the contents of this folder are cleared out.
Very useful in pentesting that any user can write in it by default, so once you have access to a machine, it serves as a good place to store things like enumeration scripts.
