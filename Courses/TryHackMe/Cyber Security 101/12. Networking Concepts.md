### [[OSI Model]] recap
7 layers, physical (1) → application (7). Mnemonic: "Please Do Not Throw Spinach Pizza Away."

| Layer | Name | Examples |
| ---- | ---- | ---- |
| 7 | Application | HTTP, FTP, DNS, POP3, SMTP, IMAP |
| 6 | Presentation | Unicode, MIME, JPEG, PNG, MPEG |
| 5 | Session | NFS, RPC |
| 4 | Transport | UDP, TCP |
| 3 | Network | IP, ICMP, IPSec |
| 2 | Data Link | Ethernet (802.3), WiFi (802.11) |
| 1 | Physical | Electrical / optical / wireless signal |

### [[TCP-IP Model]]
The implemented (vs OSI's theoretical) model — 1970s DoD, built to keep working if parts of the network go down. Groups OSI layers 5-7 into one Application layer; renames layer 3 the Internet layer.

### [[IP address]] & [[Subnetting]]
4 octets / 32 bits, e.g. `192.168.1.100`. `.0` = network address, `.255` = broadcast address.
`ifconfig` / `ip a s` (Linux) or `ipconfig` (Windows) to check yours.
`/24` = subnet mask `255.255.255.0` — leftmost 24 bits fixed across the subnet.

Private ranges (RFC 1918):
- `10.0.0.0 – 10.255.255.255` (10/8)
- `172.16.0.0 – 172.31.255.255` (172.16/12)
- `192.168.0.0 – 192.168.255.255` (192.168/16)

### [[Routing]]
[[Router]] forwards packets toward their destination, hop by hop, at Layer 3.

### [[TCP]] / [[UDP]]
Transport layer, [[Ports]] 1-65535 (0 reserved) pick the process. TCP = connection-oriented, [[Three-way handshake]] (SYN / SYN-ACK / ACK) before data. UDP = connectionless, no handshake, no delivery guarantee.

### [[Encapsulation]]
Application data → TCP/UDP segment/datagram (transport) → IP packet (network) → frame (link). Reversed on receive ([[Decapsulation]]).

### Life of a packet
Browser → HTTP(S) request → TCP handshake + send → IP adds src/dst → link layer frames it → router strips link header, reads IP, forwards → repeat until destination.

### Lab — [[Telnet]]
`telnet MACHINE_IP <port>` to talk directly to a raw TCP service:
- port 7 — echo server (repeats what you send)
- port 13 — daytime server (returns date/time, then closes)
- port 80 — HTTP: send `GET / HTTP/1.1` + `Host: telnet.thm` + a blank line
