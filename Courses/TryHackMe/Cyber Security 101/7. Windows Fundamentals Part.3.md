### Windows Update
A Microsoft service delivering security updates, feature updates, and patches for Windows and other Microsoft products (e.g. Microsoft Defender). Regular updates land on **Patch Tuesday** — the 2nd Tuesday of each month — but urgent/critical patches can be pushed out-of-band any time.

Found in Settings (also reachable via `control /name Microsoft.WindowsUpdate` from Run/CMD).

Historically, users would defer or ignore updates for a long time — largely because updates usually require a reboot. Since Windows 10, updates can be **postponed but not skipped indefinitely**: the reboot will eventually happen. This is a deliberate security trade-off by Microsoft to keep devices patched.

### Windows Security overview
Per Microsoft: "Windows Security is your home to manage the tools that protect your device and your data." Found in Settings, and covers four protection areas:

- **Virus & threat protection**
- **[[Firewall]] & network protection**
- **App & browser control**
- **Device security**

Each area shows a status icon: **green** (protected, no action needed), **yellow** (a recommendation to review), **red** (needs immediate attention).

---
### Virus & threat protection
Two parts: **Current threats** and **Virus & threat protection settings**.

**Current threats**

- Scan options: **Quick scan** (common malware locations), **Full scan** (everything on disk — can take over an hour), **Custom scan** (choose specific files/locations)
- Threat history: **Last scan**, **Quarantined threats** (isolated, periodically removed), **Allowed threats** (flagged items you chose to let run — only do this if you're certain)

**Protection settings** (Manage settings)

- **Real-time protection** — actively blocks malware from installing/running
- **Cloud-delivered protection** — faster protection using up-to-date cloud threat data
- **Automatic sample submission** — sends suspicious samples to Microsoft
- **Controlled folder access** — blocks unapproved/untrusted apps from modifying protected folders
- **Exclusions** — files/folders the antivirus skips, usually to cut false positives (⚠️ excluded items could hide real threats)
- **Notifications** — alerts about the device's health/security status

### Firewall & network protection
A [[Firewall]] controls what traffic is (and isn't) allowed through the device's ports — like a security guard checking IDs at the door. Windows Defender Firewall offers three profiles:

- **Domain** — for networks where the machine can authenticate to a domain controller
- **Private** — user-assigned, for home/private networks
- **Public** — the default profile, for untrusted networks like coffee shop or airport Wi-Fi

Each profile can be turned on/off and set to block all incoming connections. **Allow an app through firewall** shows/edits which apps have access per profile. **Advanced Settings** exposes granular rule configuration (advanced-user territory). Shortcut to open the firewall directly: `WF.msc`.

---
### Microsoft Defender SmartScreen
Protects against phishing/malware sites and apps, and against downloading malicious files. Configurable per-feature to **Warn**, **Block**, or **Off** — covers things like checking unrecognized apps/files downloaded from the web.

---
### Exploit protection & Core isolation
**Exploit protection** — built-in mitigations that make it harder for attacks to succeed against the OS (default settings are recommended unless you know exactly what you're changing).

**Core isolation / Memory integrity** — prevents malicious code from being inserted into high-security processes by isolating them in a hardware-protected virtual environment.

**Security processor** — shows the device's **[[TPM]]** (Trusted Platform Module) details. A TPM is a dedicated crypto-processor built to perform cryptographic operations and resist tampering, so malicious software can't interfere with its security functions.

---
### BitLocker
**[[BitLocker]]** is a Windows data-protection feature that encrypts an entire drive, guarding against data theft/exposure from lost, stolen, or improperly decommissioned devices. It offers its strongest protection when paired with a TPM (v1.2+), which also verifies the system hasn't been tampered with while offline.

---
### Volume Shadow Copy Service (VSS)
**[[Volume Shadow Copy Service]]** creates a consistent point-in-time snapshot ("shadow copy") of data being backed up, stored in the `System Volume Information` folder of each protected drive. When enabled (System Protection on), it allows you to create/restore to a restore point, configure restore settings, or delete restore points.

⚠️ **Security relevance:** ransomware specifically looks for and deletes shadow copies to prevent easy recovery — which is why an offline/off-site backup still matters even with VSS enabled.
