Most Linux distros use [[bash]] by default. Alternatives: [[Fish]] (user-friendly, auto spell correction, built-in syntax highlighting), [[Zsh]] (modern, advanced tab completion + spell correction, heavily customizable via oh-my-zsh, can get slow).

`echo $SHELL` : current shell
`cat /etc/shells` : list installed shells
`chsh -s /usr/bin/zsh` : change default shell permanently

### Shell scripting
Script file = `.sh`, needs execute permission (`chmod +x script.sh`), run with `./script.sh` (not just `script.sh`, or the shell looks in `$PATH` instead of the current dir).

[[Shebang]] (`#!/bin/bash`) : first line, defines the interpreter.

**Variables**
```bash
echo "Hey, what's your name?"
read name
echo "Welcome, $name"
```

**Loops**
```bash
for i in {1..10}; do
echo $i
done
```

**Conditionals**
```bash
if [ "$name" = "Stewart" ]; then
	echo "Welcome"
else
	echo "Denied"
fi
```

Comments start with `#`.
