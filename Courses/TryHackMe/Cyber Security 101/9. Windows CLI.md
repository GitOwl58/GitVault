### Navigating Directories

To find out where you currently are in the file system, use `cd` with no parameters. This is the command-line equivalent of asking "where am I?"

```
C:\Users\strategos>cd
C:\Users\strategos
```

Two useful modifiers:

- `dir /a` — shows hidden and system files too
- `dir /s` — shows files in the current directory and all subdirectories

To move into a directory, use `cd target_directory` — the equivalent of double-clicking that folder. To go back up one level, use `cd ..`:

```
C:\>cd
C:\

C:\>cd Users

C:\Users>cd
C:\Users

C:\Users>cd ..

C:\>cd
C:\
```

### Working With Files

To view the contents of a text file, use `type`, which dumps the whole file to the screen — fine for short files that fit in your terminal window. For longer files, use `more` instead: it shows one screen at a time, letting you press **Spacebar** to flip to the next page or **Enter** to move one line at a time.

```

```

This copies every file with the `.md` extension in the current directory into `C:\Markdown`.
## [[Windows]] Task Manager: Command-Line Equivalents

Windows Task Manager allows viewing and terminating running processes through a graphical interface. The command line offers equivalent functionality through two commands: `tasklist` and `taskkill`.

### Listing Running Processes

The `tasklist` command lists all running processes:

```
C:\>tasklist

Image Name                     PID Session Name        Session#    Mem Usage
========================= ======== ================ =========== ============
System Idle Process              0 Services                   0          8 K
System                           4 Services                   0         88 K
Registry                        84 Services                   0     50,700 K
smss.exe                       276 Services                   0      1,132 K
csrss.exe                      372 Services                   0      5,264 K
wininit.exe                    448 Services                   0      6,892 K
csrss.exe                      456 Console                    1      5,028 K
winlogon.exe                   516 Console                    1     11,144 K
services.exe                   584 Services                   0      7,492 K
lsass.exe                      592 Services                   0     16,108 K
svchost.exe                    704 Services                   0     23,432 K
fontdrvhost.exe                736 Console                    1      4,256 K
[...]
```

### Filtering the Output

Because this list is typically very long, filtering options are available. All filters can be viewed with `tasklist /?`.

To search for processes related to a specific image name, use the `/FI` flag to set a filter condition. For example, to find all processes named `sshd.exe`:

```
C:\>tasklist /FI "imagename eq sshd.exe"

Image Name                     PID Session Name        Session#    Mem Usage
========================= ======== ================ =========== ============
sshd.exe                      2116 Services                   0      6,992 K
sshd.exe                      2712 Services                   0      7,668 K
sshd.exe                      4752 Services                   0      7,372 K
```

### Terminating a Process

Once the process ID (PID) is known, the process can be terminated using `taskkill /PID target_pid`. For example, to terminate the process with PID `4567`:

```
C:\>taskkill /PID 4567
```

### Additional Commands

The following commands are not covered in detail here, but are worth knowing:

- `chkdsk`: checks the file system and disk volumes for errors and bad sectors.
- `driverquery`: displays a list of installed device drivers.
- `sfc /scannow`: scans system files for corruption and repairs them if possible.

The `/?` flag can be appended to most commands to display a help page describing its usage and available options.

### The `more` Command

`more` is used in two contexts:

- Displaying the contents of a text file: `more file.txt`
- Paginating the output of another command via a pipe: `some_command | more`

In both cases, output is displayed one screen at a time. Pressing **Spacebar** advances by a full page, and pressing **Enter** advances by a single line.
