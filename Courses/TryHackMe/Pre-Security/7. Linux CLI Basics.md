Basic beginner commands for [[Linux]] Terminal:

	pwd : Find out where you are.
	ls : Find out what's around you.
	ls -l : Make a list of what's around you, more precise.
	ls -al : Show hidden files
	cd : Walk around the system, ex: cd Documents
	cd .. : Go back one level
	find <Starting point> -name <filename> : Locate a file
	cat <filename> : Read the content of a file
	whoami : Prints your current username
	uname -a : Prints details about OS, Kernel version, architecture.
	uname : Prints only OS name.
	df -h : Checks disk usage, available storage space.
	ssh : Logs you in as a named username. Use "ssh username@hostname" — replace username with your actual username and hostname with the [[IP address]] or domain of the server you want to connect to.
	history : Shows all last commands typed by named user.

A good example to find information about the OS:
	cd /etc
	ls
	cat os-release

**Breakdown of the Information**

In [[CLI]]:
- `~` symbol stands for Home directory.
- `etc` stands for all configuration and information files.

**df -h Command**
![[df -h command breakdown.png]]
- `/dev/root` is the main disk of the system, mostly used, and shows how full it is.
- `tmpfs` entries are temporary filesystems stored in **RAM**, not on the physical disk.
- `/dev/shm` is a shared memory area.
- `/run/user/114` is similar temporary storage for another system user.

**uname -a command**
`ubuntu@tryhackme:~$ uname -a` → `Linux tryhackme <kernel>-aws SMP ... x86_64 x86_64 x86_64 GNU/Linux`

This gives a full line of system information — great for understanding exactly what environment you're working in.
- **Linux**: The system is running the Linux kernel.
- **tryhackme**: The hostname (the computer's name).
- **kernel version**: The kernel version installed on the machine.
- **x86_64**: The hardware platform (64-bit).
- **GNU/Linux**: The operating system type (Linux kernel + GNU tools).
