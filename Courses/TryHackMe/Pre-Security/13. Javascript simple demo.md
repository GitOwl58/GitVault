[[Javascript]] is used in most of the web pages that you visit on a day-to-day basis. Consequently, when we think of JavaScript engines, web browsers come to mind. This changed with the release of Node.js, which enables developers to build web applications with JavaScript server-side as well.

## Creating Variables

We think of a variable as a space in memory that stores a value and allows us to change this value later. For example, to keep track of the number of `tries` (attempts) a user has made, and the user's `guess`:

```javascript
let tries = 0;
let guess = 0;
```

`let` declares variables. Since the user has not made attempts yet, `tries` is set to `0`; `guess` is initialized to a value that cannot accidentally match the `secret` number the user is trying to guess.

## Creating Constants

`let` declares variables whose value can change; `const` declares constants, whose value cannot change.

`secret` holds the number to guess, and shouldn't change:

```javascript
const secret = Math.floor(Math.random() * (20)) + 1;
```

Breakdown:
- `Math.random()` gives a random decimal between 0 (inclusive) and 1 (exclusive). Example: `0.372`.
- `* 20` stretches that range to 0–(almost)20. Example: `7.44`.
- `Math.floor()` removes the decimal by rounding down. Example: `7.44` → `7`.
- `+ 1` shifts the range from `0–19` to `1–20`.

As a result, `secret` ends up being 1, 2, 3, …, up to 20.

## Displaying Output

`console.log()` displays a string on screen:

```javascript
console.log("I'm thinking of a number between 1 and 20");
```
