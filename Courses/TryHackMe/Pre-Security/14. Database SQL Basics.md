## What Is a Database

Think of a **database** as a place where a computer stores information in an organised way. A database allows the computer to search, count, and sort information very quickly. Inside a database, information is stored in **tables**.

## Tables, Columns, and Rows

A **table** resembles a spreadsheet.
- **Columns** are the titles at the top of the table. They describe the type of information stored.
- **Rows** go across the table. Each row contains one complete set of information.

## Asking Questions With SQL

[[SQL]] is a language used to ask questions of a database. These questions are called queries — a query doesn't change data, it displays the requested information from the table.

## Basic SQL Queries
- `SELECT` – choose what data to display
- `FROM` – choose where the data comes from
- `WHERE` – filter records based on a condition
- `ORDER BY` – sort results
