### [[Firewall]] 101

Firewalls operate at Layer 3 & 4 of the [[OSI Model]]
A firewall is a device, within a network, deciding what traffic is allowed to enter and exit, it acts like a network's border security.
Only an admin can configure a firewall to permit or deny traffic from entering/exiting a network, based on factors such as :
- Where is traffic coming from ? (Has the firewall been told to accept/deny traffic from a specific network)
- Where is it going to ? (Has the firewall been told to accept/deny traffic destined to a specific network?)
- What port is it for ?(Has the firewall been told to accept/deny traffic destined for port 80 only?)
- What protocol is it using ? (Has the firewall been told to accept/deny traffic that is [[UDP]],[[TCP]], or both?)
Firewalls perform packet inspection to answer these questions.
Firewalls can be a piece of hardware (often found in large businesses) that can handle a magnitude of data to residential routers like me, or a software like Snort. They can be categorised into 2 to 5 categories :

### [[VPN]]s Basics

A Virtual Private Network allows devices on separate networks to communicate securely by creating a dedicated path between them over the Internet (a tunnel).
Devices connected through this tunnel form their own private network.

![[VPN.png]]
The devices from Network 3 are still a part of Network 1 and 2, but form together to create a private network (3) that only devices connected via this VPN can communicate over.

### What is a [[Router]]?

A router's job is to connect networks, and pass data between them by [[Routing]].
Routing is the process of data, travelling across networks. It involves creating a path between them, so it can be successfully delivered.
Routers operate at Layer 3 of the [[OSI Model]].
They often have an interactive interface, website or console, allowing an admin to configure rules such as [[Port forwarding]],[[Firewall]]ing.
It is useful when devices are connected by many paths, so data can take the most optimal path.
![[Routing.png]]
Routers are dedicated to routing, and are not [[Switch]]es.
On the diagram, to know which path is the most optimal, different protocols will decide according to some factors :
- What path is the shortest?
- The most reliable ?
- Has the faster medium ? (Copper/fibre?)

### What is a [[Switch]]?

Device responsible for providing a means of connecting multiple devices.
They can facilitate many devices (3 to 63), using ethernet cables.
Switches can operate at Layer 2 and 3 of the [[OSI Model]], however switches from Layer 2 cannot operate at layer 3, so these are exclusive.

A Layer 2 switch, forwarding frames (with IP packets encapsulated within [[Frame]]s) onto connected devices, using their [[MAC address]].
These are only responsible for sending frames, to the correct device.
![[Layer 2 switch.png]]

A layer 3 switch, more sophisticated, as they can perform SOME router responsibilities, such as not only forwarding the frames to devices, but also route packets to other device using the IP protocol.
On the diagram there are 2 [[IP address]]es.
[[VLAN]], Virtual Local Area Network, allows specific devices in a network to virtually split up, to benefit from things such as an Internet connection while being treated separately.
This network separation provides security, because it means that rules in place determine how specific devices communicate with each other.
For example here Sales and Accounting can access internet, but cannot communicated with each other.
