### How websites work
When you visit a page, your browser makes a request to a web server asking for info about the page you're visiting. It will respond with data, that your browser uses to show you the page.
A web server is just a dedicated computer, somewhere else, that handles your requests.
![[Pasted image 20260812191517.png]]
There are two major componts to make up a website:
- Front end (Client side), the way your browser renders a website.
- Back end (Server side), a server that process your request, and returns a response.
### [[HTML]]
Websites are primarly created using :
- [[HTML]] to build websites and define their structure
- [[CSS]], to make them look pretty by adding styling options.
- [[Javascript]], implement complex features using interactivity.
HTML is the language websites are written in. Elements (tags) are the building blocks of HTML, pages, and tells the browser how to display content.

Simple HTML document, structure of which is the same for every website.
![[Pasted image 20260812192335.png]]
This structure has the following components :
- The `<!DOCTYPE html>` defines  page is a HTML5 document. This helps with standardisation across different browsers and tells the browser to use HTML5 to interpret the page.
- The `<html>` element is the root element of the HTML page - all other elements come after this element.
- The `<head>` element contains information about the page (such as the page title)
- The `<body>` element defines the HTML document's body; only content inside of the body is shown in the browser.
- The `<h1>` element defines a large heading
- The `<p>` element defines a paragraph
- There are many other elements (tags) used for different purposes. For example, there are tags for buttons (`<button>`), images (`<img>`), lists, and much more.
Tags can contain attributes such as class attribute, used to style an element (make the tag a different color) `<p class="bold-text">`, or the src attribute used on images to specify their location: `<img src="img/cat.jgp">`. An element can have multiple attributes, each with its purpose, `<p attribute1="value1" attribute2="value2">`.
Elements can also have an id attribute `<p id="example">`, unique to the element. Unlike class attribute, where multiple elements can use the same class, an element must have different id's to identify them uniquely. Element id's are used for styling, and to identify it by [[Javascript]].
You can view the HTML of any website by right-clicking and selecting "View Page Source" (Chrome) / "Show Page Source" (Safari).

### [[Javascript]]
JS is one of the most popular coding languages in the world, allowing your pages to become interactive.
HTML is used to create the website structure and content, while JS to control the functionality of web pages, without it a page would not have interactive elements, always static. It can update dynamically the page in real time, give functionality to change the style of a button when a particular event on the page occurs (like clicking a button), or display moving animations.
JS is added within the page source code, either loaded within `<script>`  tags, or can be included remotely with src attribute : `<script src="/location/of/javascript_file.js"></script>`
The following JavaScript code finds a HTML element on the page with the id of "demo" and changes the element's contents to "Hack the Planet" : `document.getElementById("demo").innerHTML = "Hack the Planet";` 
HTML elements can also have events, such as "onclick" or "onhover" that execute JavaScript when the event occurs. The following code changes the text of the element with the demo ID to Button Clicked: `<button onclick='document.getElementById("demo").innerHTML = "Button Clicked";'>Click Me!</button>` - onclick events can also be defined inside the JavaScript script tags, and not on elements directly.
### Sensitive data exposure
Sensitive data exposure happens when a website doesn't protect/remove sensitive information to the end-user, usually found in the website's frontend source code.
Websites are built using many HTML elements (tags), that can be seen simply by checking the page source. A developer might have forgotten to remove login credentials, link to private parts of the website, or any other sensitive data in HTML or JS.
It can be leveraged to further the attacker's access to different parts of a web app.
There could be HTML comments with temporary login credentials, and if you check the source and find this, can use these credentials to log in anywhere else on the app, or worse use it to access other backend components of the site.
When assessing a web app for security issues, one of the first things is to review the page source code for login credentials or hidden links.
### HTML Injection
HTML injection is a vulnerability occuring when unfiltered user input is displayed on the page. If a website fails sanitising user input (filter any malicious text), and that input is used on the page, then the user can inject HTML code into the vulnerable website.
Input sanitisation is crucial to keep a website secure, as infos inputed by a user in a website is often used by frontend/backend functionality.
