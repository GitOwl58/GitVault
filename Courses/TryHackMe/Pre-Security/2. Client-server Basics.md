[[HTTP]](S) is a stateless client-server protocol used for the World Wide Web. This means that each request is processed independently, without the server retaining information about previous requests.

## HTTP Commands

In the main specifications (also called Request for Comments, or RFCs), there are 9 core commands. In lingo, we use the term method instead of command:

- GET
- POST
- PUT
- DELETE
- PATCH
- HEAD
- OPTIONS
- CONNECT
- TRACE

By entering for example https://www.tryhackme.com, hitting F12 and reloading the page, we can see multiple GET requests. If we select one of these requests we can see:
- **Scheme**: Tells us which protocol was used: [[HTTP]] or HTTPS.
- **Host**: Tells us the name of the host we request resources from.
- **Filename**: Indicates which file we requested from the host. In our request, this is "/", which translates to "index.html".
- **Address**: Displays the [[IP address]] where the website is hosted. In our example, 127.0.0.1 is shown (self-hosted).
- **Status**: This field indicates whether the request was successful, e.g. "200 OK".
