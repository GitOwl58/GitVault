[[Networking]]
Networks are simply things connected. For example, your friendship circle: you are all connected because of similar interests, hobbies, skills and sorts.

In computing, a network can be formed by anywhere from 2 devices to billions — laptops, phones, security cameras, traffic lights, and even farming equipment.

![[Simple network.png]]

### What's the internet?

The **[[Internet]]** is one giant network, consisting of many networks within itself.

![[Network in a network.png]]

Imagine two people who don't speak the same language, needing a bilingual go-between to communicate — that go-between forms a network between them. The internet is like a much larger version of this.

The first iteration of the Internet was the ARPANET project in the late 1960s, funded by the US Defence Department — the first documented network in action. It wasn't until 1989 that Tim Berners-Lee invented the World Wide Web (WWW), and the Internet started being used as a repository for storing and sharing information as it is today.

![[Internet's network.png]]

The internet is made of many small (private) networks joined together by public networks (the Internet).

### Identifying Devices on a Network

To communicate, devices must be identifying and identifiable on a network. Humans have two ways of being identified: name and fingerprints — we can change our name, but not our fingerprints. Devices have the same thing:
- An [[IP address]]
- A [[MAC address]] (like a serial number)

### IP Addresses

An **[[IP address]]** (Internet Protocol) is used to identify a host on a network for a period of time. It is a set of numbers divided into four octets, calculated through IP addressing and subnetting.

![[IP Address composition.png]]

A public address identifies the device on the Internet; a private address identifies a device amongst devices.

| Device Name | IP Address | IP Address Type |
|---|---|---|
| DESKTOP-KJE57FD | 192.168.1.77 | Private |
| DESKTOP-KJE57FD | 86.157.52.21 | Public |
| CMNatic-PC | 192.168.1.74 | Private |
| CMNatic-PC | 86.157.52.21 | Public |

Two devices on the same network use their private IP addresses to communicate with each other. Data sent to the Internet from either device is identified by the same public IP address, given by your ISP (Internet Service Provider) at a monthly fee.

As more devices connect, it's becoming harder to get a public IPv4 address that isn't already in use — hence IPv6.

### MAC Addresses

Devices on a network have a physical interface, assigned a unique **[[MAC address]]** at the factory — a twelve-character [[Hexadecimal]] number.

MAC addresses can be faked in a process called "spoofing" — pretending to be another device. It can break poorly implemented security designs that trust devices talking on their network.

	Example: A firewall configured to allow communication to/from the administrator's MAC address. If a device spoofs this MAC address, the firewall thinks it's receiving communication from the administrator when it isn't.

Cafes, coffee shops and hotels often use MAC address controls in their "Guest"/"Public" Wi-Fi.

### Ping ([[ICMP]])

Ping is one of the most fundamental network tools. It uses **[[ICMP]]** (Internet Control Message Protocol) packets to determine the performance of a connection between devices — whether the connection exists or is reliable. The time taken for ICMP packets to travel between devices is measured using ICMP's echo packet and echo reply.

Ping comes installed on OSs such as [[Linux]] and Windows. Syntax: `ping IP address or website URL`
