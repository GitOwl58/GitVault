[[Windows]]
Basic beginner commands for Windows [[CLI]] / CMD (command prompt):

	cd : Find out where you are; also used to go back one level
	cd <path> : Navigates to the named directory
	dir : Find what's around you
	dir /a : Shows hidden folders
	type <name of file> : Reads the named file
	whoami : Shows which account you're logged into
	hostname : Shows the computer name
	systeminfo : Shows system info...
	ipconfig : Shows the machine's network configuration

See also: [[7. Linux CLI Basics]] for the Linux equivalent commands.
