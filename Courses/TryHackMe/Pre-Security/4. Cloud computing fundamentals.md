## Types of [[Cloud]]

The flexibility provided by cloud computing allows applications to be run in different ways, depending on your needs and level of control. Cloud providers offer multiple models for deploying and using applications, each suited to different scenarios.

**Deployment types:**
- **Public Cloud:** Used by startups, websites, and global apps because it is affordable, easy to scale, and requires no infrastructure management. Preferable for nearly every use case.
- **Private Cloud:** Used by banks, healthcare, and government organizations because it offers greater control, customization, and compliance for sensitive data.
- **Hybrid Cloud:** Used by companies like e-commerce platforms that need to keep sensitive data private while still scaling publicly during high demand.

# Main cloud service models

- **Infrastructure as a Service (IaaS):** You rent basic computing resources such as virtual [[Server]]s, storage, and [[Networking]]. You manage the OS and application; the provider manages the physical hardware.
- **Platform as a Service (PaaS):** The provider manages the infrastructure and OS. You focus on building, deploying, and running your application.
- **Software as a Service (SaaS):** You use a complete application over the internet. The provider manages everything; you access the software through a browser or app, e.g. Gmail or Zoom.
