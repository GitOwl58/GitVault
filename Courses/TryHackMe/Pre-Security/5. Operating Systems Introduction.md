## Learning Objectives
- Understand what an operating system is and the role it plays
- Explain the core duties of an operating system
- Identify common OS types and their typical use cases
- Practice interacting with an OS to gather system information

An **operating system** (OS) is the core software that coordinates everything happening on a computer. It sits between the user, applications, and the system's physical hardware, acting as the invisible manager that keeps the entire machine running as one unified system.

## Operating System Duties

| OS Responsibility      | What the OS Does                                                                                                                                                                               | Example                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| Process Management     | Creates, schedules, prioritizes, and terminates running programs. Decides how much CPU time each process gets, making multitasking feel seamless                                               | Opening multiple apps without your computer freezing                                                                              |
| Memory Management      | Allocates RAM to processes, protects each app's memory from other processes, and reclaims memory when apps close. Uses virtual memory when RAM runs low                                        | Opening multiple apps at once — each gets isolated RAM so they don't interfere or crash each other                               |
| File System Management | Organizes files into directories, handles naming, paths, permissions, metadata (name, size, type, timestamps)                                                                                   | Creating a folder, saving a photo, setting a file to "read only"                                                                  |
| User Management        | Handles multiple user accounts, authentication, and permissions to determine who can access what                                                                                                | Logging in with your password, keeping your files inaccessible to other users                                                    |
| Device Management      | Loads drivers and provides a universal interface (hardware abstraction layer), so apps can say "print this" or "play this sound"                                                                | Plugging in a mouse, printer, or external hard drive and having it work immediately                                               |

## Operating System Security
- **Authentication**: Verifies who you are through login passwords and biometrics
- **Permissions**: Controls exactly what each user and app is allowed to read, write, or execute
- **Isolation**: Keeps every process in its own protected box (kernel/user space separation)
- **System Protection**: Safeguards critical system files and settings from unauthorized changes

## OS Interfaces

**Graphical User Interface ([[GUI]])**: A graphical representation of all the information you want to access. Folder icons, windows, menus. Like tapping an icon on a map app to get directions.

**Command-line Interface ([[CLI]])**: You enter specific text-based commands to retrieve or manipulate information. Gives far more precision, control, and speed, but requires familiarity with commands. Like entering exact GPS coordinates.

## The Operating System Landscape

| Operating System Type | Primary Use Case                                          | Key Characteristics                                                |
| ---------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| Desktop               | Personal computers, daily work, gaming, content creation    | Rich graphic interface, runs many apps at once, user-focused          |
| [[Server]]            | Web hosting, databases, [[Cloud]] services, back-end        | Headless (no GUI), maximum uptime, multi-user, remote access          |
| Mobile                | Smartphones and tablets                                     | Touch-based UI, power efficient, always connected, app sandboxing     |
| Embedded              | Appliances, cars, IoT devices, smart TVs, routers            | Tiny footprint, runs on limited hardware                              |
| Virtual/Cloud         | VMs, [[Container]], cloud instances                          | Lightweight, scalable, rapid deployment                               |

## Real World Operating Systems

**Desktop**
- **[[Windows]]**: Most widely used OS on personal computers — Windows 10 (EOL), Windows 11
- **macOS**: Apple's desktop OS — Sonoma (14), Sequoia (15), Tahoe (26)
- **[[Linux]]**: A family of open-source distributions — Ubuntu, Debian, Fedora

**Server**
- **Windows**: Large networks, data centers, corporate environments — Server 2016, 2019, 2022, 2025
- **[[Linux]]**: The vast majority of web servers — Ubuntu Server, Debian, CentOS, Red Hat
- **Unix**: Large enterprises, finance, telecom, government — IBM AIX, Oracle Solaris

**Mobile**
- **Android**: Most widely used mobile OS — Android 14-16, manufacturer versions
- **iOS**: Apple's mobile OS — iOS 17, 18, 26

**Embedded and IoT**
- **Embedded Linux**: OpenWrt, Ubuntu Core, Yocto Project
- **Real-Time OS**: Guaranteed response times (aircraft controls) — FreeRTOS, VxWorks, QNX

**Virtual and Cloud**
- **[[Cloud]]/[[VM]]**: Ubuntu LTS, Amazon Linux, Rocky Linux
- **Container-optimized**: Alpine Linux, Bottlerocket AWS, Flatcar Linux

## Key Terminology
- **Operating system (OS)**: The core software that manages hardware, applications, and all system resources.
- **Kernel space**: The OS's highly privileged area with direct hardware access, home of the kernel.
- **User space**: Where regular applications run with limited permissions for safety and stability.
- **[[GUI]]**: The visual part of the OS — windows, icons, menus.
- **[[CLI]]**: A text-based interface where you type commands to control the system with precision and speed.
