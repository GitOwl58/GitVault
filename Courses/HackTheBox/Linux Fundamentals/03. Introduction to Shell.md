A Linux **terminal** (shell, command line) is a text-based I/O interface between the user and the kernel. "Console" technically means a text-mode screen rather than a window, but the terms are used loosely. Commands typed into the terminal window control the system; think of it as a text-based GUI with far more capability than clicking around.

### Terminal Emulators
![[Tmux multiplexer example.png]]
Software that emulates a terminal's function inside a graphical program, letting text-based tools run within a GUI. Terminal emulators and multiplexers (e.g. **Tmux**) extend this further: splitting one terminal into panes, working across multiple directories, and creating separate workspaces.

### Shell
The most common Linux shell is **[[bash]]** (Bourne-Again Shell), part of the GNU project: everything doable through a GUI can be done through the shell, plus automation via scripts. Other shells exist: Tcsh/Csh, Ksh, Zsh, Fish.
