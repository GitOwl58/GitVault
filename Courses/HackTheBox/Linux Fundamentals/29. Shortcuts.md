Shell shortcuts worth building into muscle memory:

| Shortcut | Action |
| --- | --- |
| `[TAB]` | Auto-complete: suggests matching directories, commands, or options |
| `[CTRL]+A` / `[CTRL]+E` | Jump to beginning / end of the line |
| `[CTRL]+[←]` / `[→]` | Jump to start of the previous/current word |
| `[ALT]+B` / `[ALT]+F` | Jump backward / forward one word |
| `[CTRL]+U` | Erase from cursor to beginning of line |
| `[CTRL]+K` | Erase from cursor to end of line |
| `[CTRL]+W` | Erase the word before the cursor |
| `[CTRL]+Y` | Paste back the last erased text |
| `[CTRL]+C` | Send SIGINT, ending the current task/process |
| `[CTRL]+D` | Close STDIN (EOF / End-of-Transmission) |
| `[CTRL]+L` | Clear the terminal (same as `clear`) |
| `[CTRL]+Z` | Suspend the current process (SIGTSTP) |
| `[CTRL]+R` | Search command history |
| `[↑]` / `[↓]` | Step through command history |
| `[ALT]+[TAB]` | Switch between open applications |
| `[CTRL]+[+]` | Zoom in |
