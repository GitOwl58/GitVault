Core commands for moving around and inspecting the filesystem, roughly the shell equivalent of using a mouse in a GUI:

- `pwd`: print the current working directory.
- `ls`: list directory contents; `ls -l` adds owner, group, size, and date; `ls -la` also shows hidden dotfiles (e.g. *.bashrc*, *.bash_history*). `ls -l /var/` can target a path without `cd`-ing there first.
- `cd <path>`: change directory; `cd -` jumps back to the previous directory; `cd ..` goes to the parent.
- `[TAB]`: shell auto-complete; pressing it twice lists all matches for a partial path.
- `clear` or **[CTRL]+[L]**: clear the terminal. **[↑]**/**[↓]** scrolls command history, **[CTRL]+[R]** searches it.

An `ls -l` line breaks down as: type+permissions, hard-link count, owner, group, size, date, name (see **[[Permissions]]** for the full breakdown). `.` marks the current directory in a listing, `..` the parent.
