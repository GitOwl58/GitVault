Every Linux file and directory has an owning user and group; permissions are assigned separately to **owner**, **group**, and **others**. Entering a directory (traversal) requires *execute* permission on it, independent of read/write; without it, even `ls` on its contents fails with "Permission denied". Execute on a directory allows traversal only, not modifying its contents; modifying (creating/deleting/renaming entries) needs *write* on the directory itself, and running a file inside it needs *execute* on that file.

The three permission bits, applied per owner/group/others:
- `r`: read
- `w`: write
- `x`: execute

An `ls -l` line like `-rwxrw-r-- 1 root root 1641 May 4 23:42 /etc/passwd` breaks down as: file type (`-` file, `d` directory, `l` link), owner perms, group perms, other perms, hard-link count, owner, group, size, date, name.

### Change Permissions: chmod
`chmod` sets permissions via group reference (`u` owner, `g` group, `o` others, `a` all) plus `+`/`-`, e.g. `chmod a+r shell` adds read for everyone. Or via octal notation summing `r=4 w=2 x=1` per owner/group/other, e.g. `chmod 754 shell` = owner rwx (7), group r-x (5), others r-- (4).

### Change Owner: chown
`chown <user>:<group> <file>` reassigns owner and/or group, e.g. `chown root:root shell`.

### SUID & SGID
Special bits (shown as `s` in place of `x`) letting a program run with the *file owner's* rights rather than the invoking user's, e.g. a SUID root binary runs as root no matter who executes it. Administrators sometimes set these on tools without realizing the tool can spawn a shell (like `journalctl`'s pager), letting any user with access escalate to root; [GTFObins](https://gtfobins.github.io/gtfobins/journalctl/) catalogues such cases.

### Sticky Bit
Set on a directory (shown as `t`/`T` in the others-execute slot) to stop non-owners from deleting or renaming files inside it, even with write access to the directory, common on shared directories like `/tmp`. Lowercase `t` means execute is also set for others; uppercase `T` means it isn't (others can't even list/traverse).
