**Solaris** is a Unix-based OS from Sun Microsystems (1990s, later acquired by Oracle), built for high-end, mission-critical enterprise environments (banking, finance, government, large-scale data centers) where stability, scalability, and security matter most. Unlike most Linux distros, Solaris is proprietary and closed-source. It ships its own hypervisor (*Oracle VM Server for SPARC*), uses the Zettabyte File System-adjacent Service Management Facility (**SMF**) for service management (vs. Linux's [[systemd]]), and the Image Packaging System (**IPS**) for packages, plus native Role-Based Access Control (RBAC) and mandatory access controls.

Key differences from Linux distros group into: filesystem, process management, package management, kernel/hardware support, system monitoring, and security.

| Task | Ubuntu/Linux | Solaris |
| --- | --- | --- |
| System info | `uname -a` | `showrev -a` (also reports patch level, hardware provider) |
| Install a package | `sudo apt-get install <pkg>` | `pkgadd -d <pkg>` (no `sudo` needed pre-Solaris 11, thanks to RBAC) |
| Change permissions | `chmod 700 <file>` | `chmod 700 <file>` (same syntax) |
| Find SUID files | `find / -perm 4000` | `find / -perm -4000` (note the leading `-`) |
| Share a directory over NFS | edit `/etc/exports` | `share -F nfs -o rw /export/home`, config in `/etc/dfs/dfstab` |
| Mount NFS | `mount <host>:/path <mountpoint>` | `mount -F nfs <host>:/path <mountpoint>` (same idea, `-F nfs` flag) |
| List a process's open files | `sudo lsof -c <process>` | `` pfiles `pgrep <process>` `` |
| Trace syscalls | `sudo strace -p `` `pgrep <process>` `` ` | `truss <command>` (also traces signals and child-process syscalls, which strace can't) |
