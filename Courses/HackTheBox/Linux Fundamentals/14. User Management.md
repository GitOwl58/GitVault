Running a command as another user (most often root) is central to Linux administration and to privilege escalation during a pentest: a file readable only by root (e.g. `/etc/shadow`) will refuse a normal user but succeed under `sudo cat /etc/shadow`.

| Tool | Purpose |
| --- | --- |
| **[[sudo]]** | Execute a command as a different user |
| `su` | Requests credentials via PAM and switches to that user (root by default), then runs a shell |
| `useradd` | Create/update a user |
| `userdel` | Delete a user and related files |
| `usermod` | Modify a user account |
| `addgroup` / `delgroup` | Add/remove a group |
| `passwd` | Change a user's password |
