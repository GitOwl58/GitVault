Linux network services matter for communicating with other hosts, transferring files, analyzing traffic, and, for a pentester, spotting misconfigurations (e.g. a user authenticating over unencrypted FTP, leaking cleartext credentials to anyone listening).

### SSH
**[[SSH]]** (commonly via **OpenSSH**) securely transmits data and commands over a network, the standard way to remotely manage Linux hosts.
- `sudo apt install openssh-server -y`: install the server.
- `systemctl status ssh`: check it's running.
- `ssh cry0l1t3@10.129.17.122`: connect as a pentester auditing a remote host.

Configuration lives in `/etc/ssh/sshd_config` (max connections, password vs. key auth, host key checking...). SSH also supports tunneling and port forwarding, letting other traffic ride an encrypted connection.

### NFS
**[[NFS]]** (Network File System) lets remote files appear local, used for centralized file management across Linux and Windows hosts. Config lives in `/etc/exports`, with access options:

| Option | Meaning |
| --- | --- |
| `rw` / `ro` | Read-write / read-only access |
| `no_root_squash` | Client's root keeps root rights on the share (dangerous) |
| `root_squash` | Client's root is downgraded to a normal user's rights |
| `sync` / `async` | Commit changes to disk before/after acknowledging the transfer |

- `sudo apt install nfs-kernel-server -y`: install.
- `mkdir nfs_sharing && echo '/home/user/nfs_sharing hostname(rw,sync,no_root_squash)' >> /etc/exports`: export a share.
- `mount <host>:/path ~/target_nfs`: mount a remote NFS share locally; misconfigured NFS shares are a known privilege-escalation vector.

### Web Server
Apache, Nginx, Lighttpd, and Caddy are the common Linux web servers, with Apache the most widespread. As a pentester, a web server can be used to stage file transfers, host a phishing clone of a target page, or serve payloads.
- `sudo apt install apache2 -y`: install Apache.
- `/etc/apache2/apache2.conf`: global config: which directories are servable, options like `Indexes`/`FollowSymLinks`, `AllowOverride`, `Require all granted`.
- `.htaccess`: per-directory overrides without touching the main config.
- `python3 -m http.server [port]`: a fast one-command alternative for quick file transfers; `--directory <path>` serves a specific folder; defaults to TCP/8000.

### VPN
A **[[VPN]]** creates an encrypted tunnel to another network, used by companies for secure remote access and by pentesters for authorized internal-network testing when on-site access isn't practical. **OpenVPN** is the most common open-source option.
- `sudo apt install openvpn -y`: install.
- `/etc/openvpn/server.conf`: server configuration (encryption, tunneling, routing...).
- `sudo openvpn --config internal.ovpn`: connect as a client using a supplied `.ovpn` profile.
