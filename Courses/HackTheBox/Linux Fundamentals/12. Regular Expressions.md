**[[Regular Expressions]]** (regex) are a pattern language for searching, matching, and manipulating text, available across most programming languages and tools (e.g. [[grep]], [[sed]]) and commonly used for input validation in web apps. A regex is a sequence of literal characters and metacharacters (symbols with no literal meaning, defining the pattern itself).

### Grouping Operators
| Syntax | Meaning |
| --- | --- |
| `(a)` | Groups part of a regex so it can be treated as one unit |
| `[a-z]` | Character class: a list/range of characters to match |
| `{1,10}` | Quantifier: how many times the previous pattern may repeat |
| `\|` | OR: matches if either side matches |
| `.*` | AND-like: matches if both sides match somewhere in the line |

With extended regex (`grep -E`), `grep -E "(my\|false)"` matches lines containing either "my" or "false" (OR); `grep -E "(my.*false)"` matches only lines containing both, in that order (equivalent to piping `grep "my"` into `grep "false"`).
