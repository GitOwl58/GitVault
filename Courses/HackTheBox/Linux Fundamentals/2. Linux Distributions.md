A Linux **distribution** (distro) is an OS built on the Linux kernel plus a chosen set of supporting software, packages, and tools. There are 600+ distros, each differing in included packages, user interface, and available tools. Popular general-purpose picks: Ubuntu, Fedora, CentOS, Debian, Red Hat Enterprise Linux. For cyber security specifically: [[Parrot OS]], Ubuntu, Debian, Raspberry Pi OS, CentOS, BackBox, BlackArch, Pentoo, with Kali Linux the most popular pentesting distro overall.

Ubuntu and Fedora suit desktop users and beginners; Debian is popular for servers and embedded systems; Red Hat Enterprise Linux and CentOS dominate enterprise computing. Since Linux is free and open source, its code can be inspected, modified, and redistributed, which is a large part of why security specialists favor it: the distro can be optimized and hardened for a specific use case.

### Debian
Known for stability and reliability, used for desktops, servers, and embedded systems. Uses the Advanced Package Tool (**[[APT|apt]]**) to handle updates and security patches, which can run manually or automatically. Debian has a steeper learning curve and a more complex setup than some distros, but in exchange offers excellent low-level control. Its long-term support releases provide security patches for up to five years, useful for systems that must run 24/7.
