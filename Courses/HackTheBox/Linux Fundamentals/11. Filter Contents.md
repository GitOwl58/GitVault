Tools for reading and filtering file/stream contents without opening a full editor. Most examples below work on `/etc/passwd`.

| Tool | Purpose |
| --- | --- |
| `more` / `less` | Interactive pagers for scrolling a file; `less` has more features and, unlike `more`, doesn't leave its output in the terminal on quit ([Q] to exit either) |
| `head` / `tail` | First / last 10 lines of a file by default |
| `sort` | Sort lines alphabetically/numerically |
| **[[grep]]** | Filter lines matching a pattern, e.g. `grep "/bin/bash"`; `-v` excludes matches, e.g. `grep -v "false\|nologin"` |
| `cut -d":" -f1` | Split on a delimiter and print a field position |
| `tr ":" " "` | Replace/translate characters |
| `column -t` | Reformat output into aligned tabular columns |
| `awk '{print $1, $NF}'` | Print specific fields ($1 first, $NF last); full (g)awk programming available |
| **[[sed]]** | Stream editor; `sed 's/bin/HTB/g'` substitutes every "bin" with "HTB" (`s` = substitute, `g` = all matches) |
| `wc -l` | Count lines |

These chain naturally through pipes, e.g.:
```
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | sed 's/bin/HTB/g' | wc -l
```
