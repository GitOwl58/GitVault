A **[[File Descriptor]]** (FD) is the kernel's handle for an I/O connection (Windows calls the equivalent a filehandle). By default every process gets three:

| FD | Stream |
| --- | --- |
| 0 | STDIN (input) |
| 1 | STDOUT (output) |
| 2 | STDERR (error output) |

![[STDIN STDOUT cat example.png]]

### Redirection Operators
- `2>/dev/null`: send STDERR to the null device, discarding it (e.g. hiding "Permission denied" noise from `find`).
- `> file`: redirect STDOUT to a file, overwriting it.
- `2> stderr.txt 1> stdout.txt`: send STDERR and STDOUT to separate files.
- `< file`: use a file's contents as STDIN, e.g. `cat < stdout.txt`.
- `>> file`: append STDOUT to a file instead of overwriting.
- `<< EOF`: read STDIN as a stream until an End-Of-File marker, e.g. `cat << EOF > stream.txt`.
- `|` (pipe): feed one program's STDOUT into another's STDIN, the basis of command chaining, e.g. `find /etc/ -name *.conf 2>/dev/null | grep systemd | wc -l`.
