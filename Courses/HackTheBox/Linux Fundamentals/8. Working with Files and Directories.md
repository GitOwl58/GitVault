Unlike Windows Explorer, Linux lets us create, edit, move, and delete files directly from the terminal: faster, scriptable, and combinable with **[[Regular Expressions|regex]]** for selective edits.

### Create, Move, and Copy
- `touch <name>`: create an empty file.
- `mkdir <name>` / `mkdir -p <path/to/nested/dirs>`: create a directory, `-p` also creates any missing parent directories.
- `tree`: visualize the directory structure.
- `mv <old> <new>`: rename or move a file/directory.
- `cp <source> <destination>`: copy a file/directory.

### Editing Files
**Nano** is a simple pager-style editor: `nano notes.txt` opens (or creates) a file for direct editing, with on-screen shortcuts (**[CTRL]+[W]** search, **[CTRL]+[O]** save, **[CTRL]+[X]** exit). Files like */etc/passwd* are worth knowing how to view/edit quickly, since misconfigured permissions on such files are a common privilege-escalation vector.

### VIM
**[[Vim]]** is a more powerful, modal text editor (an improved *Vi*) that hands off specialized tasks to external tools like `grep`, `awk`, `sed` rather than reimplementing them, keeping it small, fast, and flexible, in the Unix spirit of small composable programs. Six modes exist, the key ones being:

| Mode | Behaviour |
| --- | --- |
| Normal | All input is interpreted as editor commands (default on open) |
| Insert | Typed characters are inserted into the buffer |
| Visual | Highlights and selects a block of text for further action |
| Command | Single-line commands at the bottom (sort, replace, delete...) |
| Replace | Typed text overwrites existing characters |

`:q` (in Command mode, reached by typing `:`) quits Vim. `vimtutor` is a built-in ~25-30 minute interactive tutorial, reachable from inside Vim via `:Tutor`.
