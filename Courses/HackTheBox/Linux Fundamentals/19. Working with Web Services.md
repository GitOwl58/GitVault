Beyond IIS and Nginx, **Apache** is one of the most common Linux web servers. Its modules extend it: `mod_ssl` encrypts browser-to-server traffic, `mod_proxy` lets it act as a proxy, `mod_headers`/`mod_rewrite` manipulate HTTP headers and URLs. Server-side dynamic pages are commonly scripted in PHP, Perl, or Ruby (also Python, JavaScript, Lua, .NET). `sudo apt install apache2 -y` installs it; once running, `http://localhost` serves the default confirmation page.

![[Apache2 Ubuntu default page.png]]

### CURL
**cURL** transfers data over HTTP, HTTPS, FTP, SFTP, FTPS, or SCP directly from the shell, useful for remotely testing sites or inspecting individual requests/responses (e.g. `curl http://localhost` dumps the page source). Almost always preinstalled.

### Wget
**wget** works similarly to curl but downloads and saves the content locally by default rather than printing it, functioning as a download manager: `wget http://localhost` saves `index.html`.

### Python 3
`python3 -m http.server` starts a quick web server rooted at the current directory (default port 8000), logging every request it receives, handy both for serving files to a target and for observing what a target requests from us.
