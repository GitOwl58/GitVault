Three main ways to learn an unfamiliar tool or its options:

- `man <tool>`: opens the detailed manual page (e.g. `man curl`).
- `<tool> --help` or `<tool> -h`: quick summary of options, usually equivalent to each other.
- `apropos <keyword>`: searches every man page's short description for a keyword (e.g. `apropos sudo` surfaces `sudo`, `sudoers`, `visudo`, `sudoreplay`...).

[explainshell.com](https://explainshell.com/) is a useful web resource for breaking down a long, unfamiliar command piece by piece.
