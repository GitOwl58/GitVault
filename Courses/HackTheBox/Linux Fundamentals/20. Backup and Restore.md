Common Ubuntu backup tools: **[[Rsync]]** (open-source, efficient: only transfers changed parts of a file, good for large datasets over a network), **Duplicity** (GUI, uses rsync as a backend, adds encryption and remote/cloud storage such as S3), **Deja Dup** (GUI, simplified rsync front-end with encryption support). Encrypting backups (via GnuPG, eCryptfs, or LUKS) protects sensitive data at rest.

### Rsync
- `sudo apt install rsync -y`: install.
- `rsync -av /path/to/mydirectory user@backup_server:/path/to/backup/directory`: backup a directory; `-a` (archive) preserves permissions/timestamps, `-v` is verbose.
- `rsync -avz --backup --backup-dir=/path/to/backup/folder --delete ...`: add compression (`-z`), incremental backups, and removal of files on the remote that no longer exist locally.
- `rsync -av user@remote_host:/path/to/backup/directory /path/to/mydirectory`: restore, same syntax reversed.

### Encrypted Rsync
`rsync -avz -e ssh ...` routes the transfer over an **[[SSH]]** tunnel, adding confidentiality and integrity on top of rsync's own transfer logic.

### Auto-Synchronization
Combine rsync with **[[Cron]]** for scheduled, unattended backups: wrap the rsync command in a script (e.g. `RSYNC_Backup.sh`), `chmod +x` it, then add a crontab entry like `0 * * * * /path/to/RSYNC_Backup.sh` to run it hourly.
