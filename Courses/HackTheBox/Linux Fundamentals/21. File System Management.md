Linux supports many filesystem types (ext2/3/4, XFS, Btrfs, NTFS...), each with different strengths: ext2 for basic use, Btrfs for data integrity/snapshots, NTFS for Windows interoperability. The Linux **[[File System]]** is Unix-derived and hierarchical, built on an **[[Inode]]** table: metadata (permissions, size, type, owner...) for every file and directory, functioning like a database the OS queries to manage files. Stored content is either a **regular file** or a **directory** (a container for files); **symbolic links** reference other files/directories elsewhere in the tree. `ls -il` shows each entry's inode number alongside its usual listing.

### Disks & Drives
`fdisk` (also `gpart`, `GParted`) is the main Linux disk/partition management tool: `sudo fdisk -l` lists disks and their partition tables (size, type, sectors). Partitioning divides physical storage into logical sections, each formattable with its own filesystem and mountable independently.

### Mounting
Mounting attaches a partition/drive to a directory in the filesystem hierarchy, after which it's accessible like any other folder.
- `/etc/fstab`: defines filesystems mounted automatically at boot (device/UUID, mount point, type, options).
- `mount` (no args): list currently mounted filesystems.
- `sudo mount /dev/sdb1 /mnt/usb`: mount a device to a mount point.
- `sudo umount /mnt/usb`: unmount; requires sufficient permissions and that no process still has it open (`lsof | grep <user>` helps find blockers).
- Adding `noauto` to an `/etc/fstab` entry stops it being auto-mounted at boot/shutdown-sensitive scenarios.

### SWAP
**Swap** space extends physical memory: when RAM is exhausted, the kernel moves inactive pages to swap, freeing RAM for active processes. Created with `mkswap` (sets up the swap area) and activated with `swapon`. Ideally on its own dedicated partition/file, separate from the rest of the filesystem, and encrypted since sensitive data can land there temporarily. Swap also underlies hibernation, where system state is saved to disk before power-off and restored on next boot.
