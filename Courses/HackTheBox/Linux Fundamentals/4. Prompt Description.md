The bash prompt is a string shown when the shell is ready for input, typically `<username>@<hostname><cwd>$`. The home directory is shown as `~`. The trailing character marks privilege level: `$` for a normal user, `#` for root (e.g. `root@htb[/htb]#`). If a shell is caught via an exploit (e.g. a reverse shell), the PS1 variable may not be set, so all we see is a bare `$` (unprivileged) or `#` (privileged/root) prompt.

The prompt is customizable via special characters and variables in *.bashrc*:

| Sequence | Meaning |
| --- | --- |
| `\\d` | Date (Mon Feb 6) |
| `\\D{%Y-%m-%d}` | Date (YYYY-MM-DD) |
| `\\H` | Full hostname |
| `\\j` | Number of jobs managed by the shell |
| `\\n` | Newline |
| `\\r` | Carriage return |
| `\\s` | Shell name |
| `\\t` / `\\T` | Current time, 24h / 12h |
| `\\@` | Current time |
| `\\u` | Current username |
| `\\w` | Full working directory path |

Customizing the prompt can add IP address, date/time, or last-command exit status, which is useful during penetration tests when correlating actions with `.bash_history`. Tools like [bash-prompt-generator](https://bash-prompt-generator.org/) and [powerline](https://github.com/powerline/powerline) help build one.
